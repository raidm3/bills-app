## Bills App

# Frameworks & Libraries
- Next.js
- React.js
- Typescript
- Tailwind CSS
- PostgreSQL
- Prisma

# Getting started

```sh
pnpm install
pnpm lint
pnpm dev
```

# Build

```sh
pnpm build
```

# Deploy to Vercel

Setup .env file with secrets from Vercel Database Setup page.

```sh
pnpm build
npm i -g vercel
vercel
```
